# 🌍 EcoLogi-Sync: Calculadora de Huella de Carbono

## 📝 Descripción
**EcoLogi-Sync** es una herramienta interactiva diseñada para concienciar sobre el impacto ambiental de la logística circular. Esta aplicación permite a las empresas y usuarios particulares calcular cuánto **CO2** dejan de emitir a la atmósfera al reutilizar envases en lugar de desecharlos.

El proyecto nace como una solución digital para visibilizar los beneficios de la economía circular, aplicando una interfaz moderna, limpia y altamente intuitiva.

## 🚀 Funcionalidad
La aplicación web ofrece las siguientes capacidades:
* **Cálculo Dinámico:** Algoritmo en JavaScript que procesa el ahorro de emisiones basado en el volumen de envases gestionados.
* **Validación de Datos:** Sistema de control que evita cálculos erróneos o valores negativos.
* **Interfaz Responsiva:** Diseño adaptativo (Mobile First) que permite su uso en smartphones, tablets y ordenadores.
* **Feedback Visual:** Notificaciones dinámicas que muestran el éxito del ahorro ambiental.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica para una mejor accesibilidad.
* **CSS3 (Custom Properties):** Diseño moderno con uso de variables, degradados y efectos de profundidad.
* **JavaScript (ES6):** Lógica de cálculo y manipulación del DOM en tiempo real.

## 📁 Estructura del Proyecto
Siguiendo las mejores prácticas de desarrollo y los requisitos del portfolio:
* `src/`: Contiene los archivos HTML (Página principal y Sobre el autor).
* `assets/`: Recursos del sistema (CSS para estilos y JS para la lógica).
* `docs/`: Documentación técnica, manuales y guías de arquitectura.
