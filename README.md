# EcoLogi-Sync - Calculadora de Huella de Carbono
Proyecto desarrollado para la gestión de logística circular y sostenibilidad.

## Estructura
- `/src`: Código fuente HTML.
- `/assets`: Recursos (CSS, JS).
- `/docs`: Documentación del proyecto.

## Cómo usar
Abra `src/index.html` en cualquier navegador moderno.
